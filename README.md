# Testes Automatizados para a Dog API (PT-BR)

Projeto de automação de testes da Dog API utilizando:
- Java
- Rest Assured
- Cucumber (BDD)
- Gradle

## Como executar

1. Ter Java 11+ instalado.
2. Rodar:
```bash
gradle test
```

## Cenários escritos em Português (PT-BR)
Os cenários seguem o padrão Gherkin.
